# Generation provenance

Every real generation this project ran, with the prompt that produced it and the job it came from.
Nothing here is regenerated by the build; the browser-ready copies under `web/public/examples/` are
derived from these by `web/scripts/prepare-example.mjs`, which never modifies anything in this tree.

## Burruss Hall — one building, five prompts

Four photographs (`burruss-medieval-4view/inputs/`), one footprint (OSM
[way/32963472](https://www.openstreetmap.org/way/32963472), 800 Drillfield Drive), five styles. Each
run is four `image-to-image` calls plus one `multi-image-to-3d`, `nano-banana` and `meshy-6`,
strength 0.8, 60k target. The four styled concepts are kept in each `result/`, not just the first.

| Directory | Style | Placement | IoU |
| --- | --- | --- | --- |
| `burruss-medieval-4view/` | Medieval fantasy ruin | rejected | 73.13 % |
| `burruss-solarpunk/` | Solarpunk Bloom | rejected | 70.56 % |
| `burruss-noir/` | Neon Noir | rejected | 70.41 % |
| `burruss-fantasy/` | Enchanted Citadel | rejected | 69.90 % |
| `burruss-scorched/` | Scorched Nebraska | rejected | 59.60 % |

Because the photographs and the footprint are identical across all five, the IoU spread is a
measurement rather than noise: the destructive prompt costs 13.5 points because it asks for collapse
and rubble, while the additive ones cost about three.

Two runs carry a caveat worth keeping:

- `burruss-medieval/` is the same prompt from a **single** view, kept as the comparison that shows
  why four views matter — the front elevation is right and the rear half is a rounded blob with the
  foreground trees baked in as geometry.
- `burruss-noir/` froze at `submission-unknown` when its 3D submission was interrupted. The provider
  task list was reconciled first and showed no task had been created, so nothing had been billed;
  `finish_reconstruct.py` then made that one call by hand. Its `result/generation.json` records this
  under `recovery`. **A `submission-unknown` is never auto-retried** — see `server/app/pipeline.py`.
- `burruss-green-scape/` **failed** at redesign (`ProviderError: Unrecognised fixture task id`, a
  provider-mode mixup). It has no model and is kept only as the record of that failure.

## Gilbert Place — a second building, the same apocalypse

`gilbert-scorched/`: three photographs of a 2024 terracotta-and-glass research building at 220
Gilbert Street, OSM [way/43972334](https://www.openstreetmap.org/way/43972334), recorded height 30 m.
Placement is **review** at IoU 33.67 % with essentially zero spill — the opposite failure mode to
Burruss. The mesh is not misplaced; it is too small to fill the footprint.

## Data and Decision Sciences Building

- **Photo:** `photo.png` (operator supplied). **Footprint:** OSM
  [way/1174211880](https://www.openstreetmap.org/way/1174211880), cached as `way-1174211880.osm`,
  727 Prices Fork Road. Identity operator-confirmed.
- **Prompt:** `Modern Hokie Stone academic building with large glass curtain walls, preserve
  roofline and massing.`
- `live/` is the genuine completed Meshy run: 1,746,050 triangles, 62,465,636 bytes, placement
  **rejected** at IoU ≈ 52.6 %, heading unverified, height inferred. Its concept is a subtle restyle
  — this is why the pitch moved to Burruss.
- Its footprint is complex and concave, and all four candidate rotations score within 0.005 of each
  other, so the placement is rotationally indeterminate as well as poor. It is a useful honest
  review-path sample and is kept for exactly that.
- `web/public/examples/dds/` is the browser-ready copy: **59,962 triangles**, **12,907,244 bytes**,
  meshoptimizer at a 0.005 error limit, refitted after simplification, still rejected at 52.6204 %.

## Old Trafford

`old-trafford/` holds two `reconstruct`-only runs from four attributed Wikimedia Commons views
(`attribution.json` carries each author and licence) plus two aerial views. **There is no styled
concept and no footprint**, so it demonstrates reconstruction only, not the product's before/after
claim, and it ships in no example.

## Fixture files — not AI output

The loose `concept.png` (185 bytes), `model.glb` (a 12-triangle box) and `manifest.json` in this
directory come from the **fixture provider**. They exercise the offline pipeline and are neither
Meshy output nor a model of any building. The fixture mesh is deliberately expected to fail the
real-footprint check, and the cached manifest records that rejection.

## Re-running a generation

`run_style_generation.py <name>` runs one authorized paid job into its own data directory, resumable
by request key and never resubmitting. `samples/*/.data/` holds the raw per-job downloads and is
gitignored — the same bytes are in each `result/` and `bundle.zip`.
